# Linux-Programming-Practice

리눅스 프로그래밍 수업에서 진행한 실습 과제 정리 저장소입니다. 리눅스 기본 명령어·셸 사용법부터 파일/디렉터리 다루기, 권한, 프로세스 제어, 패키지 관리를 거쳐 C 프로그램의 개발 과정(선행처리·분할 컴파일·gcc·make)까지 이어지는 실습 흐름을 담고 있습니다.

## 배운 것 / 깨달은 것 / 성취한 것

리눅스 명령어와 셸을 다루는 것부터 시작해서 파일과 디렉터리, 권한, 프로세스 제어, 패키지 관리를 거쳐 C 프로그램이 실제로 빌드되는 과정까지 실습하면서, 가장 크게 체감한 건 "명령어를 외우는 것"과 "그 명령어가 왜 그렇게 동작하는지 이해하는 것" 사이의 차이였습니다. 5장에서 하드링크와 심볼릭 링크를 직접 만들어보면서는 단순히 rm으로 파일을 지우는 것과 링크된 파일을 지우는 것의 차이를 몸으로 확인했고, 9장에서 `ls -l` 결과의 각 항목(권한 문자열, 하드링크 개수, 소유자)을 하나씩 뜯어보고 기호 모드로 퍼미션을 직접 바꿔보면서 리눅스의 권한 체계가 어떻게 구성되는지 이해할 수 있었습니다. 10장에서 `find`를 오래 걸리는 조건으로 백그라운드 실행시켜놓고 jobs와 ps로 잡 번호와 PID를 추적해 종료해보는 실습에서는, 포그라운드·백그라운드가 단순한 개념이 아니라 실제 셸이 프로세스를 어떻게 관리하는지를 직접 다뤄봐야 감이 온다는 걸 깨달았습니다. 특히 31~34장에서 편집→선행처리→컴파일→링크로 이어지는 개발 과정을 배우고, main.c·mylib.h·mylib.c로 파일을 나눠 분할 컴파일을 해보고, 마지막엔 Makefile을 직접 작성해 make로 빌드해보면서는, 지금까지 IDE가 자동으로 처리해주던 빌드 과정을 직접 손으로 구성해봐야 gcc와 make가 무엇을 대신 해주고 있었는지 제대로 이해할 수 있다는 걸 배운 게 가장 큰 성취였습니다.
전체적으로 리눅스 프로그래밍을 배운다는 건 명령어 목록을 외우는 게 아니라, 셸이 프로세스를 어떻게 다루고 소스코드가 어떻게 실행 파일로 만들어지는지를 직접 손으로 확인해나가는 과정이었다는 걸 챕터를 거듭할수록 깨달았습니다.

## 실습 목록

### 1장 - 리눅스와 가상머신
UNIX 운영체제의 역사(벨 연구소, 켄 톰슨·데니스 리치)와 특징을 조사하고(1-1), 가상머신(Virtual Machine)의 개념과 타입1(VMware ESXi, Hyper-V, Xen, KVM)·타입2(VMware Workstation, VirtualBox, Parallels 등) 하이퍼바이저의 종류를 조사한 도입부입니다.

📁 [1장/](./01장/)

### 2장 - 리눅스 명령어와 셸
리눅스 명령어의 정체(셸이 실행하는 프로그램)와 GUI 셸에서 명령어를 대체하는 방식, 셸과 커널의 차이, 프롬프트 문자열에서 `~`의 의미, 셸 스크립트의 개념을 조사한 장입니다.

📁 [2장/](./02장/)

### 4장 - 디렉터리와 경로
디렉터리·서브 디렉터리·작업 디렉터리·홈 디렉터리, `~`·`.`·`..`, 상대경로/절대경로 같은 기본 용어를 정리하고, ls 명령어의 다양한 옵션을 실습한 장입니다.

📁 [4장/](./04장/)

### 5장 - 파일과 디렉터리 다루기
touch/mkdir로 파일과 디렉터리를 만들고 tree로 구조를 확인한 뒤, rm으로 삭제하고 cp/mv로 복사·이동하는 실습, 그리고 하드링크와 심볼릭 링크의 차이 및 확인 방법을 다룹니다.

📁 [5장/](./05장/)

### 6·7장 - 검색과 에디터
find 명령어로 파일 위치를 검색하고(`*.txt`와 `*.txt` 따옴표 유무의 차이 포함), man으로 명령어 사용법을 확인하며, vi 에디터로 hello.c 소스를 작성하고 cat으로 내용을 확인하는 실습입니다.

📁 [6-7장/](./06-07장/)

### 8장 - 환경변수 PATH
환경변수 PATH의 기능(명령어를 찾는 디렉터리 목록을 콜론으로 구분해 저장)을 설명하고, 윈도우에서 PATH에 새 경로를 추가하는 방법을 조사한 장입니다.

📁 [8장/](./08장/)

### 9장 - 파일 권한
`ls -l` 출력 결과(파일 종류, 소유자/그룹/기타 사용자 권한, 하드링크 개수, 소유자 등)를 해석하고, 기호 모드로 퍼미션을 수정하며, 관리자 권한이 필요한 경우와 파일·디렉터리 퍼미션의 의미 차이를 다룹니다.

📁 [9장/](./09장/)

### 10장 - 프로세스와 잡 제어
여러 잡을 백그라운드/포그라운드로 실행·종료하고 `jobs` 명령으로 목록을 확인하는 실습, 그리고 `find / -name .bashrc`처럼 오래 걸리는 명령을 백그라운드로 실행한 뒤 `ps`로 PID를 확인하고 잡번호로 종료하는 프로세스 제어 실습입니다.

📁 [10장/](./10장/)

### 20장 - 패키지 관리(apt)
apt update(패키지 목록 갱신)와 apt upgrade(실제 업그레이드)의 차이, apt remove/purge/autoremove의 차이, 설치된 패키지 확인 방법, 그리고 gcc 패키지의 정보 조회·설치 여부 확인·설치를 실습한 장입니다.

📁 [20장/](./20장/)

### 31장 - 프로그램 개발 과정과 선행처리
C 프로그램 개발 과정(편집→선행처리→컴파일→링크→실행)의 각 단계를 설명하고, 특히 선행처리 단계에서 헤더 파일을 포함시키거나 매크로를 치환하는 등의 작업을 다루는 장입니다.

📁 [31장/](./31장/)

### 32장 - 분할 컴파일
main.c/mylib.h/mylib.c로 프로젝트를 나누어 두 정수 중 큰 수를 구하는 프로그램, 함수값을 계산하는 프로그램, 삼각형 클래스(Triangle)를 분할 컴파일 구조로 작성하는 실습입니다.

📁 [32장/](./32장/)

### 33장 - gcc
정수 2개를 입력받아 최댓값을 구하는 프로그램을 분할 컴파일 구조로 C언어로 작성하고, 동일한 과제를 C++로도 작성해 gcc/g++ 컴파일 과정을 비교하는 실습입니다.

📁 [33장/](./33장/)

### 34장 - make
GCC 강의노트의 실습과제 1, 2번 프로그램을 Makefile을 작성해 make 명령으로 빌드하고, 소스파일·Makefile·실행 결과를 정리하는 실습입니다.

📁 [34장/](./34장/)
